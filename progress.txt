# UI 모던 미니멀 리디자인 (인디고 · 다크모드) — 완료

Airbnb 의 형태 언어를 가져오되 강조색만 인디고(#4F46E5)로 바꿨다.

## 참고 문서와 다르게 간 것

| 문서 | 이 프로젝트 | 이유 |
|---|---|---|
| Rausch #ff385c 단일 강조색 | 인디고 #4F46E5 | 요구사항 |
| "Airbnb 웹에 다크 모드가 없다" | 다크 모드 지원 | 요구사항이 우선 |
| Airbnb Cereal VF | Inter | 라이선스 폰트라 못 쓴다. 문서가 지목한 대체재 |
| 다크 CTA 를 밝은 인디고로 | #5d5fef | #6366f1 은 흰 글자 대비 4.47:1 로 AA 미달 |

## 두 번에 나눠 한 이유

1차에서는 색과 형태만 토큰화하고 **스케일을 예전 그대로 뒀다**(본문 14px,
섹션 여백 32px, 폭 1024px). 그랬더니 라이트/다크 토글 말고는 바뀐 티가 나지
않았다. 이 시스템에서 "generous" 를 만드는 건 색이 아니라 **본문 16px 과
섹션 사이 64px** 이다. 2차에서 스케일을 문서 값으로 맞추고 나서야 달라졌다.

새 화면을 만들 때도 같다. `.t-display` `.t-section` `.t-title` `.t-body`
`.t-meta` 를 쓰고 임의 크기를 적지 말 것.

## 가져온 것

- 강조색은 하나다. 화면 대부분이 캔버스+잉크이고 인디고는 CTA·활성 메뉴·완료 상태에서만 터진다
- 그림자 단계는 하나뿐(--shadow-float). 깊이는 헤어라인과 면 분리로 만든다
- 활자는 문서 토큰 그대로: h1 28/700, 섹션 20/600, 카드 제목 16/600,
  본문 16/400, 메타 14/400
- 여백도 문서대로: 주요 밴드 사이 64px, 카드 사이 16px, 카드 내부 24px
- 컨트롤 8px / 카드 14px. 그 사이 반경은 쓰지 않는다
- 컨트롤 치수도 문서대로: CTA 48px, 입력 56px, 콘텐츠 최대폭 1280px

## 구조

- `app/globals.css` — 색·반경·그림자 토큰과 프리미티브(.btn .field .card .badge)
- `lib/theme.ts` — 테마 선택 + <head> 동기 초기화 스크립트
- `components/ThemeToggle.tsx` — 시스템/라이트/다크

## 새 화면을 만들 때

**숫자 팔레트(slate-700 등)를 직접 쓰지 말 것.** 토큰 이름을 쓰면 다크 모드가
따라오지만, 숫자를 쓰면 그 자리에서만 깨진다. 유일한 예외는 모달 스크림
(`bg-black/50`)이고 이건 사양 그대로다.

버튼과 입력은 새로 조합하지 말고 `.btn` / `.field` 를 붙인다. 페이지마다 다시
만들면 높이와 반경이 조금씩 어긋난다.

## 검증

# 박스 없는 구성 (2차 디자인 패스)

문서의 "화면의 95%는 그림자도 테두리도 없는 흰 바탕" 을 적용했다.
색과 크기를 아무리 맞춰도 모든 영역을 1px 박스에 담으면 평범한 대시보드로 보인다.

- `.card` 는 무테두리. 집을 수 있는 것만 `.card-liftable` 로 hover 때 뜬다
- `.well` 은 "여기에 놓는다" 는 뜻이 필요한 곳에만 (칸반 열, 연결 계획 미리보기)
- `.rule` 로 목록 행을 나눈다. 박스 대신 얇은 선
- 문서에 있는데 빠뜨렸던 `hairline-soft #ebebeb` 복원, `surface-strong` 을 #f2f2f2 로 정정
- Luxe(#460479)를 이월 배지 하나에만 사용. 그 이상 늘리면 "강조색은 하나" 가 무너진다
- 사이드바 활성 표시는 왼쪽 2px 규칙 (문서의 product-tab-active)

## E2E 가 원격 DB 를 쓰고 있었다 — 이 함정을 반복하지 말 것

`playwright.config.ts` 는 "MONGODB_URI 를 비워 둔다" 고 주석만 달아 두고 실제로는
비우지 않았다. `next dev` 가 `.env` 를 읽으므로, 개발용 `.env` 에 MONGODB_URI 가
생긴 순간부터 **E2E 전체가 원격 Atlas 운영 DB 에 붙어 돌았다.**

증상: 매 요청이 네트워크를 타면서 실행 시간이 두 배가 되고, 타임아웃이
테스트마다 옮겨 다녔다. 드래그 헬퍼를 세 번 고쳤지만 원인이 아니었다.
그 사이 Atlas 에 테스트 계정 7개와 문서 1889건이 쌓였고 나중에 지웠다.

교훈: **환경 격리는 주석이 아니라 값으로 해야 한다.** process.env 가 .env 파일보다
우선하므로 `MONGODB_URI: ''` 를 명시하면 로컬 폴백을 탄다.

# Airbnb 디자인 문서 정확 벤치마크 (Rausch)

## 왜 다시 했는가

1차·2차 패스는 벤치마크라 부르기 어려웠다. 대조해 보니 색은 값이 틀리거나 빠진 것이
5개, 활자는 문서 18개 토큰 중 6개만 옮겼고 그중 2개는 행간·자간이 달랐다.
사용자가 "당장 색 구성만 봐도" 라고 지적했고, 확인 후 강조색을 인디고에서
문서의 **Rausch #ff385c** 로 교체했다.

## 검증 방식 — 눈이 아니라 스크립트

globals.css 를 파싱해 문서 값과 1:1 대조했다. 색 19개, 활자 15개 전부 일치.
대비도 WCAG 공식으로 라이트/다크 12개 조합을 계산했다.

## 지켜야 하는 것

**숫자 팔레트와 임의 크기를 화면 코드에 쓰지 않는다.** 토큰 이름과 `.t-*` 유틸에서
고른다. 유일한 예외는 모달 스크림 `bg-black/50` 이고 사양 그대로다.

**강조색은 하나다.** Rausch 는 CTA·활성 메뉴·완료·진행률에만. Luxe(#460479)는
이월 배지 하나에 예외로 빌려 쓴 것이고 여기서 더 늘리면 전제가 무너진다.
실제로 완료 배지까지 Plus 마젠타로 줬다가 강조색이 4개가 되어 되돌렸다.

**문서에 있어도 표면이 없으면 넣지 않는다.** legal-link(법적 밴드 전용),
error-hover(오류 링크 전용), plus(Plus 서브브랜드), rounded.xl(카테고리 스트립),
display-md(3단계 제목 위계)는 이 앱에 자리가 없어 뺐다. 정의만 해 두면 죽은 코드다.

## 활자 토큰은 반드시 utilities 레이어에

`.t-*` 를 `@layer components` 에 두면 `.field` / `.btn-sm` 이 선언한 font-size 와
명시도가 같아지고, 소스 순서상 뒤에 오는 프리미티브가 이긴다. 그래서
`field t-caption-sm` 이 13px 이 아니라 **16px** 로 렌더됐다 — 화면 코드는 토큰을
쓰는 것처럼 보이는데 픽셀은 토큰이 정하지 않는 상태였다.

교체 전에는 그 자리에 `text-xs` 가 있었고 그건 utilities 라 항상 이겼다. 토큰
이름으로 바꾸는 순간 승패가 뒤집힌 것이다. 빌드 CSS 오프셋으로 확인했다
(이전: t-caption-sm 21828 < field 23645 / 이후: field 6763 < t-caption-sm 18273).

## 이번에 잡은 진짜 버그

1. **spacing 토큰 이름 충돌** — `--spacing-sm` 은 Tailwind 의 `max-w-sm`/`w-md` 와
   같은 네임스페이스다. 노출하는 순간 `max-w-sm` 이 24rem 이 아니라 **8px** 로
   해석돼 로그인 카드가 64px 로 찌그러졌다 (computed max-width 실측으로 확인).
   → 명명 spacing 토큰을 두지 않는다. Tailwind 기본 스케일이 같은 픽셀을 낸다.
2. 목표 상세에 `17%` 가 세 번 나왔다 → ProgressBar 에 `showPercent` 를 두고
   큰 숫자가 이미 있는 화면에서는 끈다.

## 대비 — AA 미달 3건 (실측)

| 조합 | 라이트 | 다크 | 성격 |
|---|---|---|---|
| 흰 글자 on `#ff385c` (CTA) | **3.52** | **3.52** | 원본 시스템의 성질. 문서 충실도를 택함 |
| `--muted-soft` (배경별) | **3.11~2.90** | **4.50~3.97** | 예외 아님. 어느 배경에서도 4.5 미만 |
| 흰 글자 on `--primary-disabled` | **1.37** | 13.73 | WCAG 1.4.3 비활성 예외 |

나머지 6개 조합(ink·body·muted·primary-accent·luxe·danger)은 양쪽 다 통과한다.

흰 바탕 위 "글자" 로 쓰는 강조색은 `--primary-accent #c1103f`(6.15:1)를 따로 뒀다.

`--muted-soft` 는 문서 값(#929292)을 지키면 AA 를 넘길 수 없다. 다크 canvas 의
4.4970 도 4.5 **미만**이다. 문서 충실도를
택했으므로 그대로 두되, 정보를 담은 글자에 이걸 쓰지 말 것 — 플레이스홀더·드래그
손잡이 같은 장식 표면용이다. 현재 사용처: `app/page.tsx:127·260·273`,
`components/TodoCard.tsx:56·96`, `components/TodoForm.tsx:162`, `.field::placeholder`.

## E2E 를 돌릴 때

- **실행 중에 저장소 안의 파일을 건드리지 말 것.** prd.json 을 고쳤더니 next dev 가
  리로드되며 mongod 가 죽어 `ECONNREFUSED 27017` 로 줄줄이 실패했다. `.omc/` 도 감시 대상이다.
- **로그를 지운 직후 바로 폴링하지 말 것.** 파일이 다시 만들어지기 전이라 이전 실행의
  `EXIT=` 를 읽고 끝난 줄 안다. 실제로 두 번 속았다. 크기가 0이 아닌지 함께 볼 것.
- 셋업(loginAs/resetData)의 HTTP 는 일시적 ECONNRESET 에 1회 재시도한다. 단언은
  재시도하지 않는다 — 그러면 진짜 결함을 가린다. 재시도가 일어나면 로그에 남는다.
