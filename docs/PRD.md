1. Why - 목적
일일 할일이 주간 계획, 1년 목표와 단절되어 관리되는 문제 해소
오늘 처리한 할일이 상위 목표 달성에 얼마나 기여했는지 즉시 확인 가능하게 함
상태 변경을 드래그 앤 드롭으로 단순화해 관리 비용 최소화
진행률을 수동 입력이 아닌 자동 산출로 처리해 기록 누락 방지
2. Who - 타깃 사용자
연간 목표를 세우지만 일일 실행으로 분해하지 못하는 개인 사용자
칸반 방식(todo/doing/done)에 익숙한 실무자
주간 단위로 회고, 계획을 반복하는 사용자
보조 대상: 팀 단위가 아닌 1인 사용 기준, 협업 기능은 범위 외
3. User Flow
온보딩 단계
1년 목표 등록(제목, 기간, 설명)
해당 목표 하위에 주간 계획 생성
일일 사용 단계
할일 생성 시 주간 계획 선택(미선택 시 미분류로 저장)
할일 카드를 todo/doing/done 컬럼 간 드래그 앤 드롭으로 이동
상태 변경 시 소속 주간 계획 진행률 자동 재계산
주간 단계
주간 뷰에서 계획별 진행률, 완료/미완료 할일 확인
미완료 할일 다음 주로 이월 처리
연간 단계
1년 목표 뷰에서 하위 주간 계획들의 평균 진행률 확인
4. 기능 요구 사항
P0 - 핵심 기능
할일 CRUD
생성: 제목(필수), 마감일, 상태(기본값 todo), 주간 계획 연결
수정: 모든 필드 인라인 수정 지원
삭제: 소프트 삭제 후 30일 보관, 진행률 계산에서 즉시 제외
조회: 일일 뷰(오늘 기준), 주간 뷰(주 단위 필터)
상태 관리
상태값 3종 고정: todo, doing, done
상태 전환은 방향 제약 없이 전 구간 허용
done 전환 시 완료 시각 기록
드래그 앤 드롭
컬럼 간 이동으로 상태 변경
동일 컬럼 내 이동으로 순서 변경
드롭 즉시 낙관적 UI 갱신 후 서버 반영, 실패 시 원위치 롤백
기간 구조
3계층: 1년 목표 > 주간 계획 > 할일
1년 목표: 연도 단위, 다수 주간 계획 보유
주간 계획: 주 시작일 기준 식별, 1개 1년 목표에 연결(선택)
할일: 1개 주간 계획에 연결(선택), 미연결 상태 허용
구조 연결
상위 항목 삭제 시 하위 항목은 미분류로 전환(연쇄 삭제 금지)
할일의 주간 계획 재지정 가능, 재지정 시 양쪽 진행률 재계산
주간 진행률 자동 반영
산식: (주간 계획에 연결된 done 할일 수) / (전체 연결 할일 수) × 100
연결 할일 0건이면 0%로 표기
할일 생성, 삭제, 상태 변경, 연결 변경 시 즉시 재계산
1년 목표 진행률은 하위 주간 계획 진행률의 평균값으로 산출
P1 - 추가 기능
미완료 할일 다음 주 일괄 이월
반복 할일(일간, 주간 주기)
주간 회고 메모 필드
1년 목표 하위 주간 진행률 추이 그래프
할일 태그, 우선순위 필드 및 필터
키보드 단축키 기반 상태 변경(드래그 앤 드롭 대체 수단)
소프트 삭제 항목 복구 뷰
